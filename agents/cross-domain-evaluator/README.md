# Cross-Domain Misinfo Robustness Evaluator

Evaluates pipeline robustness across domain shifts (politics, health, economics, climate) using automated decision-rule probing.
Triggers weight recalibration when cross-domain accuracy drops below threshold.

Reference: Ding et al. (2025) "A Multi-Agent Framework with Automated Decision Rule Optimization for Cross-Domain Misinformation Detection." arXiv:2503.23329.
