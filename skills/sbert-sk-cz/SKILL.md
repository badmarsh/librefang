# SBERT SK/CZ Skill

This skill provides semantic embeddings using a Slovak/Czech fine-tuned model (e.g., `slovakbert`). It is primarily used by the `temporal-kg` and the `disinfo-orchestrator` for deduplicating claims and finding semantically similar past cases.

## Integration

Use this skill when comparing the similarity of two Slovak/Czech texts.
